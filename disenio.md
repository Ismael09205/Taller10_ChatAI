Instrucciones: Implementación de UI/UX para Chat con IA – Expo Go
1. Diseño de referencia en Figma

URL del diseño de Figma:

https://www.figma.com/design/7fYE4qoyjojV6Yiz8isbvd/Mansa-App--Community-?node-id=0-1&t=hpJWwIWoyDhDLWEv-1

Utiliza el MCP de Figma y su plugin para acceder al diseño, analizar sus pantallas, componentes, estilos y recursos visuales.

2. Objetivo

Implementar una interfaz móvil profesional para una aplicación de chat con inteligencia artificial, utilizando fielmente el diseño proporcionado en Figma.

3. Tecnología obligatoria
React Native.
Expo Go.
TypeScript (si el proyecto ya lo utiliza).
Compatible con Android e iOS.
Mantener la arquitectura y dependencias actuales del proyecto.
4. Instrucciones de implementación
Analiza primero la estructura del proyecto y sus componentes existentes.
Utiliza Figma MCP para inspeccionar el diseño y extraer sus estilos, componentes, imágenes e iconos.
Replica fielmente la interfaz de Figma, respetando colores, tipografías, dimensiones, espaciados y distribución.
Implementa las pantallas necesarias:
Inicio del asistente IA.
Conversación de chat.
Historial de conversaciones.
Menú y configuración.
Adjuntar imágenes y documentos.
Estados de generación de respuestas.
Implementa componentes reutilizables para mensajes, campos de entrada, botones, tarjetas y encabezados.
Integra el diseño con la navegación existente.
Adapta la interfaz a diferentes tamaños de pantalla.
Respeta las áreas seguras de Android e iOS mediante SafeAreaView o la solución existente.
Mantén separada la interfaz de usuario de la lógica de comunicación con la IA.
Conserva las funcionalidades y conexiones existentes.
5. Reglas importantes
No utilices componentes HTML ni CSS web.
Utiliza exclusivamente componentes compatibles con React Native y Expo Go.
No instales dependencias innecesarias.
No reemplaces la configuración actual de Expo.
No alteres las APIs ni las variables de entorno existentes.
No inventes elementos visuales que contradigan el diseño de Figma.
No utilices datos simulados si ya existen conexiones reales.
No elimines funcionalidades existentes.
6. Validación final
Comprueba que la aplicación inicia correctamente con Expo Go.
Verifica la navegación entre pantallas.
Comprueba la adaptación a Android e iOS.
Revisa que los componentes coincidan visualmente con Figma.
Corrige errores de diseño, renderizado y funcionamiento.
Resultado esperado

Una aplicación móvil de chat con inteligencia artificial, visualmente fiel al diseño de Figma, moderna, responsive, con componentes reutilizables y completamente funcional dentro del entorno Expo Go.

IMPORTANTE: Antes de programar, inspecciona completamente el diseño mediante Figma MCP. No comiences a implementar hasta comprender su estructura y sus pantallas.
